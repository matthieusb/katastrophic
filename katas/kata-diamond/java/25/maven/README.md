# Diamond kata

Given a letter, print a diamond starting with ‘A’ with the supplied letter at the widest point.

For example: print-diamond ‘C’ prints:
```
  A
 B B
C   C
 B B
  A
```

For example: print-diamond ‘B’ prints:
```
 A
B B
 A
```


## Pre-requisites

You need **java 25** and **maven** installed

## Installation

Simply run:

```bash
mvn clean install
```

## Development

Test watch:
```bash
mvn test
```
